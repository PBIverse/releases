# PBIverse Desktop Companion Apps

Official desktop companion applications for [PBIverse](https://www.pbiverse.com) — the community platform for custom Microsoft Power BI visuals, TMDL templates, and DAX configurations.

## 📥 Official Downloads

You can download the latest verified releases from our [Releases Page](https://github.com/PBIverse/releases/releases/latest):

* **`PBIuser.exe`** — Consumer helper app for seamless visual pasting into Power BI Desktop.
* **`PBIcreator.exe`** — Creator studio app for packaging and exporting custom visuals.
* **`PBIuninstall.exe`** — Dedicated 1-click uninstaller and registry cleaner.

---

## 🔒 Security & Privacy

* **Local Execution Only**: The applications run 100% locally on your machine.
* **Zero Data Logging**: The software never logs keystrokes, does not access unrelated data, and transmits zero personal data.
* **Terms & EULA**: Governed by the [PBIverse Software EULA & Terms](https://www.pbiverse.com).
